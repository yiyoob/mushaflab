## D71: GitHub Actions CI stays off; the full gate runs locally before every merge
Status: accepted (Eisa, 2026-11-23)
Date: 2026-11-23
Context: The `ci` workflow (macOS runner, ~20 min a run) has been `disabled_manually` on
yiyoob/mushaflab since 2026-10-23; its last run failed in 5 s with no steps run.
Options: move CI to a Linux runner and switch it back on; keep it off and run `just gate` locally.
Decision: Keep it off. `just gate` (with `MUSHAF_FULL=1`) runs locally before every merge to
`main`; `just gate-fast` before every commit. The workflow file is kept current, with a header
saying it is switched off, so it can be turned back on.
Consequences: The merger is responsible for the gate; a PR description states that `just gate`
passed and on which commit.
